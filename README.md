# Music Store Data Analysis Using SQL

## About the Project
This project focuses on analysing a digital music store database using PostgreSQL. The objective is to explore customer purchasing behaviour, music preferences and sales performance through SQL queries.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Project Analysis

### 1. Basic Analysis
- Senior-most employee
- Countries with the most invoices
- Top invoice values
- Best customer based on spending

### 2. Intermediate Analysis
- Rock music listeners
- Top 10 rock artists
- Tracks longer than average song length

### 3. Advanced Analysis
- Amount spent by each customer on artists
- Most popular music genre in each country
- Highest-spending customer in each country

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- JOINs
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions

## Repository Structure
- SQL Queries: Basic, Intermediate and Advanced SQL scripts
